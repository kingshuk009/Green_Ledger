# Methodology Registry

This directory is intentionally a registry, not a copy of copyrighted standards.

Current design references:
- India CCTS Offset Mechanism / BEE-approved methodologies.
- Verra VCS VM0042 Improved Agricultural Land Management v2.2, including June 11, 2026 Corrections and Clarifications.
- ISO 14064-2 principles as referenced by the Indian Offset Mechanism procedure.
- GHG Protocol Land Sector and Removals Standard as a broader accounting reference.

Official methodology PDFs should be obtained from their publishers and version-pinned in the project documentation. Do not redistribute copyrighted documents inside this repository unless permitted.
