# Data sources

WoSIS is the preferred public observed-soil research source where the required
properties and licensing permit use. ISRIC provides dynamic WFS/GraphQL access and
static snapshots.

Current documentation:
https://docs.isric.org/globaldata/wosis/faq-wosis.html

SoilGrids is a modeled product and should be treated as a secondary spatial
reference/prior rather than primary observed ground truth for model evaluation.
